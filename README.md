# Live Architecture

Embeddable widgets and shared assets for architecture tooling.

## Widgets

| Widget | Description |
|--------|-------------|
| [`icon_palette/`](icon_palette/) | Lucid-style icon picker over the local draw.io icon corpus |

## Shared assets

- [`icons/`](icons/) — SVG icon sets downloaded from [icons.diagrams.net](https://icons.diagrams.net/)

## Quick start (icon palette)

```bash
cd icon_palette/web
npm install
npm run dev
```

From the repo root you can run `npm run dev` after dependencies are installed in `icon_palette/web`. See [`icon_palette/README.md`](icon_palette/README.md).
